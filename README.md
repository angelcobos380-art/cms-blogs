# CMS Admin

Panel de administración headless en **React 19 + TypeScript + Vite**, desacoplado del backend FastAPI.

## Desarrollo

```bash
cp .env.example .env
npm install
npm run dev
```

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run build` — `tsc -b && vite build`
- `npm run typecheck` — verificación de tipos
- `npm run lint` — ESLint
- `npm run test` — Vitest
